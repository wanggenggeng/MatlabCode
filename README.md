# MatlabCode

## 简易计算器

使用 MATLAB 编写的命令行计算器，无需额外工具箱。

支持加、减、乘、除、负数、小数和科学计数法；检查无效输入、除数为零及计算溢出。
每次输入两个数和一个运算符，不解析数学表达式。

## 使用方法

在 MATLAB 中将当前文件夹切换到本仓库，运行：

```matlab
calculator
```

按提示输入，例如：

```text
第一个数：12.5
运算符（+ - * /）：*
第二个数：4
12.5 * 4 = 50
```

计算后可继续输入；在任意提示处输入 `q` 或 `Q` 退出。
输入有误时显示提示，然后从第一个数重新开始。

也可以直接调用函数：

```matlab
result = calculator(12, '+', 3);   % 15
result = calculator(7, '/', 2);    % 3.5
result = calculator(-2.5, '*', 4); % -10
```

函数调用收到无效参数时会抛出错误。运算使用双精度浮点数。
