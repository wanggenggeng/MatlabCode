# 简算 · 网页简易计算器

一个下载后就能使用的网页计算器。只需浏览器，无需 MATLAB、安装软件、启动服务器或联网。

## 下载使用

1. **[点击下载 ZIP](https://github.com/wanggenggeng/MatlabCode/archive/refs/heads/main.zip)**，然后解压。
2. 找到解压目录里的 **`index.html`**。
3. 双击 `index.html`，用 Chrome、Edge、Firefox 或 Safari 打开，即可开始计算。

也可以在 GitHub 打开 [`index.html`](index.html)，点击右上角 **Download raw file（下载原始文件）**。保存时保留 `.html` 扩展名，下载这一个文件就足够。

## 功能

- 加、减、乘、除，小数、正负号和百分比。
- 连续计算、重复按等号、退格和全部清除。
- 除数为零及数值溢出提示；输入新数字即可重新开始。
- 展示本次打开的最近六条计算记录，刷新或关闭页面后清空。
- 支持鼠标、触屏和键盘，适配窄屏。
- 样式、图标和脚本全部内置，不发送网络请求。

## 键盘操作

| 按键 | 操作 |
| --- | --- |
| `0`–`9`、`.` | 输入数字和小数点 |
| `+`、`-`、`*`、`/` | 加、减、乘、除 |
| `Enter` 或 `=` | 得出结果 |
| `Backspace` | 删除最后一位 |
| `Esc` 或 `Delete` | 全部清除 |
| `%` | 当前数字除以 100 |
| `F9` | 切换正负号 |

按普通计算器的输入顺序连续计算，例如 `2 + 3 × 4 =` 得到 `20`。
`%` 始终将当前数字除以 `100`，例如 `50 %` 得到 `0.5`。
最多输入 12 位数字，计算结果保留最多 12 位有效数字，适合日常近似计算。

## 修改页面

用文本编辑器打开 `index.html` 即可修改界面和逻辑。所有内容都在这一个文件中，不需要构建或安装依赖。
